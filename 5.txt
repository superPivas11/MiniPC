================================
       Micro OS Readme
================================

Это текстовый документ для теста.

Формат файла: .txt (код *3)

Команды:
- 1111#NN*F - скачать файл
- 1210#NN - запустить скрипт
- 1310 - список файлов
- 2110#0 - подключить WiFi

Форматы:
*1 = .app (приложение)
*2 = .scr (скрипт)
*3 = .txt (текст)
*4 = .img (картинка)
*5 = .upd (обновление)
